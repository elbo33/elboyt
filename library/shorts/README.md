# shorts/

Final vertical (1080x1920) renders from `ai-math-shorts-generator`.

One folder per short, named by its title:

```
shorts/
  <title-slug>/
    <title-slug>.mp4     the final render
    render/
      <planner>.ts       the planner that produced it
      storyboard.json
      scenes/            generated Manim code + support/
      COMMAND.md         exact command to reproduce
```

Only the final `.mp4` is kept — no per-scene clips, caches, or preview frames.
