## 03. The Problem
Say we want to compute a factorial, or walk a nested folder tree, or flatten
a list of lists. Each of these has the same shape: solve a smaller version
of the same problem, then combine the results.

## 04. Base Case & Recursive Case
Every recursive function needs two things: a base case that stops the
recursion, and a recursive case that shrinks the problem toward that base
case. Miss either one and you get infinite recursion — or a stack overflow.
